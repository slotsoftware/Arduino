Solución: Elegoo UNO R3 no aparece en la ventana de Chrome

Revisa estos 4 puntos clave para que Windows/Mac y Chrome detecten tu placa

¿Te sale "No se puede abrir el puerto" (Failed to open serial port)? SOLUCIÓN RÁPIDA

Ese mensaje significa que Chrome SÍ ve tu Elegoo UNO R3, pero Windows tiene el puerto COM bloqueado porque otro programa lo está usando ahora mismo. Haz estos 3 pasos en orden:

  1. Cierra por completo el programa Arduino IDE (aunque no tengas el Monitor Serie abierto, el Arduino IDE 2.x bloquea el puerto en segundo plano).
  2. Cierra otras pestañas de Chrome donde hayas intentado abrir KRONOS antes (solo una pestaña puede usar el USB a la vez).
  3. Desenchufa el cable USB azul de tu Elegoo, espera 3 segundos y vuélvelo a enchufar. Luego pulsa "Conectar Arduino USB".
1. ¿Estás abriendo el programa dentro de la vista previa o en una pestaña propia? Muy frecuente

Las vistas previas incrustadas bloquean a veces la lista de dispositivos USB por seguridad. Descarga el programa en tu ordenador y hazle doble clic para abrirlo directamente en una pestaña normal de Google Chrome:

2. No busques el nombre "Elegoo" en la lista: busca el chip serie

Las placas Elegoo UNO R3 casi nunca aparecen con la palabra "Elegoo" o "Arduino". En la ventana flotante de Chrome aparecen con uno de estos nombres:

  • USB-SERIAL CH340 (COM3, COM4...) ← Muy común en placas compatibles
  • Dispositivo serie USB (COMx) ← Nombre genérico en Windows 10/11
  • ATmega16U2 o Arduino Uno (COMx)
3. Cierra el "Monitor Serie" del programa Arduino IDE

Si tienes abierto el programa Arduino IDE en tu PC (especialmente si tienes la lupa del Monitor Serie abierta), Windows bloquea el puerto USB para un solo programa y Chrome no podrá usarlo ni conectarse. Ciérralo antes de conectar aquí.

4. ¿Aparece en el "Administrador de Dispositivos" de Windows?

Abre el Administrador de dispositivos de Windows y despliega "Puertos (COM y LPT)". Si al enchufar y desenchufar el cable USB azul de tu Elegoo no aparece ningún puerto `COM`, prueba en otro puerto USB directo de la placa base (evita hubs USB sin alimentación) o instala el driver CH340 / Arduino USB Driver.
